# Capstone_1

## Project Overview

This project analyzes sales data for EmporiUm, a student bookstore chain that also sells technology products, art supplies, and other merchandise.

Using SQL, I will answer business questions related to an assigned sales territory and provide insights to support management decisions.

## Objectives

- Analyze sales data using SQL queries
- Answer sales manager business questions
- Export results to CSV for reporting
- Create a Pivot Chart to visualize findings
- Present results through a video demo and presentation
- Complete additional exploratory analysis when applicable
